1. Executive Summary & Live Production Environments

Aceolution Finance is a company-internal spend, reimbursement, and expense management platform operating at a global level across different projects, regions, and currencies. It enables internal employees worldwide to raise project-scoped expenses in their local currencies, normalizes amounts to a corporate USD base via real-time FX rates, enforces strict segregation of duties (SoD) through project-scoped manager approvals, and enables central Accounts Payable (AP) to disburse partial or full payments with proof receipts.

4. Frontend & Backend Technical Specifications

💻 Frontend Architecture (ace_finance_frontend)

  • Framework: Next.js 16 (App Router) + React 19 + TypeScript
  • Styling: Tailwind CSS 4
  • Build: Static export (output: "export") compiling into ./out
  • Hosting: Azure Static Web Apps (finance.aceolution.com)
  • Deployment: npm run deploy:azure (automated via deploy-azure-swa.ps1)
  • Role Scoping:
    • REQUESTER: Submit & track assigned projects only
    • APPROVER: Approve/reject assigned projects only
    • PROCESSOR & ADMIN: Global company visibility
  • UI Panels: Submit Expense split view with right-side tracker ("What happens next" & "Recent requests"), header project & date filters
  • Documentation: Password-gated SOP & slide guides at /docs-guide & /demo-guide

⚙️ Backend Architecture (ace_finance_backend)

  • Framework: NestJS 11 + TypeScript + Node.js 20 LTS
  • Database: MongoDB Atlas (Mongoose ODM) with /ace_finance database
  • Authentication: JWT Passport, Email OTP (SHA-256), TOTP Authenticator, demo persona bypass (isDemo: true)
  • Storage: Azure Blob Storage (ace-finance-files) with folders /invoices (<= 5MB) and /receipts
  • Email Fallback Chain:
    1. Azure Communication Services (ACS) Email
    2. Resend HTTPS API
    3. SMTP / Gmail Transport
  • Automation: Cron schedulers for invoice due dates (dispatches reminders at 3 days & 1 day before due date)
  • Hosting: Azure App Service (Linux, South India region, Port 3001)
  • Health Probes: GET / and GET /health

5. Internal Corporate Governance & Segregation of Duties

  • Project Budget Isolation: Employees and Project Leads can only submit and review expenses against projects explicitly assigned to them by administrators (assignedProjects).
  • Segregation of Duties (SoD): The Project Lead approving the expense cannot disburse funds; disbursement is exclusively handled by the Central Accounts Payable team.
  • Proof Enforcement: Submissions strictly require vendor invoices (PDF, JPG, PNG <= 5MB); disbursements strictly require proof-of-payment receipts.
  • Immutable Audit Trail: Every action (submission, approval, partial payment, full payment, change request, rejection) writes to an immutable history log with operator name, timestamp, and financial delta.
