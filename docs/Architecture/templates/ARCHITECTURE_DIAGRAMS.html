3. Consolidated Frontend & Backend Technical Specifications
Complete summary of tech stack, environment configurations, and deployment pipelines.

💻 Frontend Architecture (ace_finance_frontend)

  • Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
  • Build: Static export (output: "export") to ./out
  • Hosting: Azure Static Web Apps (finance.aceolution.com)
  • Deployment: One-command deploy via npm run deploy:azure / deploy-azure-swa.ps1
  • Roles: REQUESTER & APPROVER (scoped to assigned projects); PROCESSOR & ADMIN (global)
  • UI Panels: Submit Expense right-hand tracker, profile project chips, header project & date filters
  • Guides: Password-gated SOP & slide presentation at /docs-guide & /demo-guide

⚙️ Backend Architecture (ace_finance_backend)

  • Stack: NestJS 11, TypeScript, Node.js >=20 <23
  • Database: MongoDB Atlas (Mongoose) with /ace_finance database
  • Storage: Azure Blob Storage (ace-finance-files), folders /invoices & /receipts
  • Auth: JWT Passport, Email OTP (SHA-256), TOTP Authenticator, demo persona bypass (isDemo)
  • Email Chain: 1. Azure Communication Services (ACS), 2. Resend, 3. SMTP
  • Automation: Cron schedulers for invoice due dates (3-day & 1-day reminders)
  • Hosting: Azure App Service (Linux, South India region, Port 3001)
